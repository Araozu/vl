# VL docs site

Astro + Tailwind v4 + Svelte. Docs & API sections are stubs for now.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build
```

- `src/pages/index.astro` — landing + Svelte playground stub
- `src/pages/docs/` — overview, getting-started, language, cli
- `src/pages/api/` — overview, driver, frontend, backend
- `src/components/Playground.svelte` — interactive stub (Svelte)
